# STM32F407 车辆仪表验证清单

| 场景 | 操作 | 通过判据 |
|---|---|---|
| 构建 | `pio run -e black_f407zg` | 固件成功生成。 |
| TFT/LVGL | 上电显示仪表主页 | 屏幕刷新、中文字体和页面切换正常。 |
| 摇杆 | 上下左右、短按、长按 | UI 产生对应导航事件；悬空摇杆不会持续误触发。 |
| SD | 插入 FAT 格式 SD 卡 | 挂载成功，日志或媒体读写功能可用。 |
| CAN1 | 注入 500 kbps 动力帧 | RX 计数和动力数据 UI 更新。 |
| CAN2 | 注入 250 kbps 车身帧 | 车身状态被解析、UI 更新。 |
| F103 联调 | 连接 ECU 节点 | 可观察 BMS/电机状态，驾驶模式命令形成闭环。 |

记录 CAN 分析仪截图和关键串口/屏幕证据，区分台架模拟与实际车辆测试。
